# Briefing topics

Add one Markdown file per continuing interest, for example `ai-advances.md` or
`local-news.md`. Include preferred sources, questions, depth, and topics to avoid.
Never store credentials or sensitive personal information here.

During an activity, name a topic file explicitly if you want ChatGPT to use it.
For recent news, O'KeegSan must still retrieve current sources rather than relying
only on this repository.
